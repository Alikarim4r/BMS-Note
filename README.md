# BMS Note

BMS Note is a local, offline-first Windows companion for facility-management notes linked to BMS assets.

## Download

Use the Releases section to download the latest Windows installer:

- BMSNote-Setup-1.0.0-win-x64.exe — recommended Windows installer
- BMSNote-Portable-1.0.0-win-x64.zip — portable version
- SHA256SUMS.txt — integrity checksums

## Important

- Windows x64
- Self-contained; no separate .NET installation is required
- Local data is stored on the Windows computer
- BMS observation is designed to be read-only
- The current binaries are not code-signed, so Windows SmartScreen may show an Unknown publisher warning

## Version

Current release: 1.0.0
